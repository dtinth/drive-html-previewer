Is this safe?

Yes. This web app talks directly to Google Drive from your browser — your files never pass through any server of ours, because there isn't one.

When you sign in, this app can only open the one file you choose or the file a link points to. It can't look at anything else in your Google Drive.

The file is shown in an isolated window-within-the-page, so whatever's in it can't touch your Google account or read anything else on this page.

It's also open source, so you can read exactly what it does.
